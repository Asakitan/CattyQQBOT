# 源码自修复周预算

`catty_self_repair.budget.WeeklyBudget` 使用独立 SQLite 文件，不复用人格语气进化的日账本。自然周按 UTC+8 周一 00:00 划分；无时区的测试时间按 UTC+8 解释。硬上限为 100,000,000 token；`weekly_token_budget` 可以降低额度，已持久下调的额度不会因为重开进程或恢复较大配置自动升高。

每次实际模型请求先按输入上限加输出上限预留，收到可用 usage 后单次结算。`snapshot.used` 包含本周已结算量和所有尚未结算请求的完整预留，`pending` 是未结算笔数。缓存输入和推理输出都属于预算，不扣除缓存命中数。

超时、缺少 usage、非法数值、超出预留的用量、进程崩溃都不会自动退款。未结算请求跨周、重启继续占用；延迟结算会保守计入起止及观察到的所有中间周。时钟回拨不会抹掉已观察到的周期。额度精度依赖服务商遵守配置的上下文/输出上限并准确返回 usage。

`BEGIN IMMEDIATE` 串行化跨线程和跨进程的判额与写入，`synchronous=FULL` 保证 SQLite 提交；只允许独占创建者初始化新账本。数据库损坏、结构/版本异常或已打开账本被删除时直接报错，不把不可读取状态当成零消耗。校验会扫描账本，随历史记录数线性增长；无自动清债、提额或修库操作。

离线覆盖见 `tests/test_self_repair_budget.py`：周界、年界、跨周未知用量、时钟回拨、降额、线程/进程并发、真实子进程退出与数据库异常；不调用模型接口。
