# 会话 11 · 图片与表情的自然回应

## 目标与范围

- 让 bot 结合语境自然回应用户的图片与表情，而不是机械复述识别内容；完成验证后合并并部署。

## 已完成

- 修复当前图片原图透传时未注册看图提示；当前图、引用图、上下文图、网页图和识图文字降级使用共享的自然接话指导。
- QQ `face`、`mface` 及 Unicode 表情进入提示上下文；已知 ID 或协议名称提供线索，未知含义不猜，无 URL 表情包保留可用摘要。近期对话也保留表情线索。
- 去掉旧图片关键词强制反应段，保留出站表情、复读及既有群聊唤醒规则。明确要求识别、描述、转录、翻译、解题或分析图片时仍完成任务。
- 部署前核对本地和生产的 4 个源码及 4 个测试基线一致。生产状态文档与本地既有版本不同；状态和模块清单确认为旧版，架构文档和会话索引读取超时，本轮未覆盖生产文档。
