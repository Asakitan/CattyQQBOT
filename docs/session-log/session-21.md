# 会话 21 · 明确语音请求

## 目标与范围

- 用户明确要求语音时优先发声，跳过随机概率，保留冷却和失败回落；不更换聊天模型或语音权重。

## 已完成

- 远端截图对应回合由 `gpt-6.1-terra` 回复，日志无语音工具调用。按生产配置重建的 37 个工具包含语音工具；机机语音配置和 9 条备用语音可读。
- `voice_reply.py` 识别常见明确语音请求，排除否定、用户自己发送和询问操作；`reserve_slot` 对明确请求跳过概率，但保持群/私聊冷却和主人既有豁免。
- `tools.py` 的完整及精简 schema 优先支持明确语音请求；`__init__.py` 给该回合附短提示，模型未调用工具时可将短回复转换为语音条，并在合成前原子占用群冷却。
- 工具拒绝不再记为已发声；后台待发与已发声区分，分段文本按工具实际优先级处理。后台失败按已送达文字去重并回落，中间语音条发送失败时回落文字；慢合成可能先发文字再补语音。
