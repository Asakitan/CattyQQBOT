# 会话 40 · 主动冒泡等待新消息

## 目标与范围

同群主动冒泡后没有其他新消息时，不再发起下一次主动生成，节省模型请求。各人格继续共用每群计划，保留原有活跃度、时段、冷却和发送回执规则。

## 已完成

- 调度器以最近确认发送及发送结果未知的时间作为门槛；同群有新的群消息、群文件上传或已确认的机器人后续群消息时，仍需满足原活动条件才可生成。明确失败和未发送的生成结果不新增门槛。
- 群事件只记录最近活动时间；每次主动发送建立单调时钟检查点，冒泡自身不触发下一轮。发送完成后的目的记账期间出现的新消息不会丢失。
- 活动时间保存在运行时内存，重启后发送状态仍在，但须重新观察群消息。时钟相等或发送结果未知时采取保守判断。
